# 进度（2026-10-23 至 2026-11-01）

日期：2026-10-23 至 2026-11-01

## 摘要

本阶段（10/23 至 11/1）完成了形成能预测的验证器循环实验（H2–H4），并补充了数据来源和对照。在合成数据上，同样用 2000 个标签时，LLM 写的特征比只用 Magpie 的平均误差低 0.025 eV/atom，迁移到真实 DFT 数据上低 0.035 eV/atom。但循环（每轮根据验证误差改写特征）和记忆（每轮附带历史记录）本身没有可靠增益，循环的收益大致相当于多给 3000 个标签。直接学习结构的 CGCNN 远好于 LLM 特征。

## 主要结论

1. **循环与一次性**：循环（L0）比一次性（O）平均误差低 0.003 eV/atom，95% 范围为 −0.011 到 +0.004，包含 0，没有可靠差别。
2. **记忆**：加记忆的循环（L1）比不加记忆的循环低 0.002 eV/atom，范围为 −0.009 到 +0.004，包含 0。
3. **与数据量的关系**：L1 与用 5000 个标签的 Magpie 基本持平（差 −0.0015，范围 −0.014 到 +0.010）。循环的收益大致相当于多给 3000 个标签。
4. **与 CGCNN 的对比**：同样 2000 个标签，CGCNN 误差为 0.167，L1 为 0.209，LLM 特征明显更差。
5. **迁移到真实 DFT 数据**：在 2000 个真实 HOLDOUT 上，L1 比只用 Magpie 低 0.035 eV/atom（范围 −0.044 到 −0.026），显著。
6. **记忆探针（H3，回顾）**：LLM 误差与随机森林误差的比值，真实与合成之差为 −0.105（范围 −0.244 到 +0.035），不显著。目前不能说 LLM 对真实材料有记忆优势。

## 1 研究问题与实验设置

本阶段考察两个问题：LLM 写的特征能否在同样标签数下优于普通方法；循环与记忆是否带来额外收益。

- **任务**：预测形成能，指标为平均绝对误差（MAE，单位 eV/atom，越小越好）。同时报告按题（行加权）和按模板组（组加权）两种口径。
- **真实 DFT 数据**：从 Matbench mp_e_form（132,752 条，Materials Project 的 DFT 形成能）中抽取，固定划分为 TRAIN 2000 个、HOLDOUT 2000 个。
- **真实 CHGNet 标签**：同一批结构用 CHGNet 0.3.0 弛豫后计算形成能。严格可用子集为 TRAIN 1992 个、HOLDOUT 1998 个。CHGNet 标签与 DFT 标签在 HOLDOUT 上的 MAE 为 0.0634 eV/atom。
- **合成数据**：TEST 1000 个（333 个模板组）、POOL 5000 个，两者模板不重叠。合成成分的约化式按要求不在 Matbench 全表中（用于新颖性检查），合成结构用 StructureMatcher 去重，标签流程与真实 CHGNet 标签相同。排除了 He、Ne、Ar、Kr、Xe、Rn。
- **数据公开**：POOL、TEST、HOLDOUT 的标签与 LLM 的请求回复记录均已公开在 GitHub 仓库的 `data/` 目录中。之后的记忆测试不再是盲测。
- **一次性（O）**：一次性给 2000 个标签，LLM 写 20 个特征，按验证误差选最好的一组。
- **循环（L0）**：共 20 轮，每轮看验证误差和预测最差的样本，改写特征，每轮最多 75 个标签查询。最终 2000 个标签。
- **循环加记忆（L1）**：在 L0 基础上，每轮附带历史记录（特征贡献、失败原因、查询结果、笔记）。
- **对照**：只用 Magpie（matminer 的成分特征，HGB），以及 CGCNN，各用 2000 或 5000 个标签。
- **统计**：2000 次按组 bootstrap 的 95% 范围；三个种子取算术平均，不做集成。
- **模型**：gpt-6.1-sol（推理强度 high），禁用工具和联网。全局 LLM 调用 183/300。

## 4 循环与记忆的解释

- 循环相对一次性没有可靠增益。L1 与 5000 标签的 Magpie 基本持平，说明循环的效果大致相当于多给 3000 个标签。
- 加记忆的 L1 减 L0，反映的是整套记忆、反馈和查询流程的差异，不是笔记本身的因果效应。
- 验证误差随轮次下降，但训练标签从 575 增加到 2000，验证集的成员也在变化。因此验证误差下降不能直接归因于特征改进。

## 8 局限性

- 循环在合成数据上进行，真实数据只用于迁移测试。
- 合成成分不在 Matbench 全表中，但这不能证明 LLM 没有见过这些材料。
- 负形成能不等于凸包稳定，也不等于可以合成。
- CHGNet 标签与 DFT 标签在 HOLDOUT 上的 MAE 为 0.0634 eV/atom，两者并不完全一致。
- 验证标签进入反馈，验证集随揭示增长，不同轮的验证误差不能直接比较。
- 真实 HOLDOUT 的历史累计读取次数无法确认，本阶段记为 1 次。
- 第 3 阶段出现过一次 PermissionError，文件名没有记录。重新核对时，清单中的文件都可以读取。
- 全局 LLM 调用 183/300，第 4 阶段新增 0 次。
